# Vivek Sahu — 3D Portfolio

Interactive personal portfolio featuring day/night themes, an animated background, a 3D project gallery, GitHub auto-sync, skills, certifications, resume, and feedback.

## Run

Open `index.html` in a browser. For a public website, enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root)**.

## Required assets

The HTML refers to `VIVEKRESUME.pdf` and files under `certificates/`. Those binary files must be uploaded separately from the latest portfolio ZIP to this repository, keeping the same paths. Until they are uploaded, certificate and resume links will not work.

## Feedback

The form needs a Google Apps Script Web App deployment URL configured in the website. Do **not** store Google credentials or API secrets in this public repository.

## Projects

Project cards load public repositories from the GitHub account; a live demo button requires a valid repository homepage/deployment URL.
