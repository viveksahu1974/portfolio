## One required GitHub action

1. Go to **https://github.com/new** while signed in as `viveksahu1974`.
2. Set **Owner** to `viveksahu1974` and **Repository name** to exactly `viveksahu1974`.
3. Choose **Public**. GitHub should indicate that this repository is special and can display a profile README.
4. Tick **Add a README file**, then click **Create repository**.
5. Open the `README.md`, click Edit (pencil), and replace it with the entire contents of **[the prepared profile README](./README.md)**. Commit the change.
6. Open **https://github.com/viveksahu1974** and refresh. The banner references this repository's public file: `portfolio/github-profile/assets/hero.svg`.
